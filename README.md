# Protocolo de Currículos

Sistema web desenvolvido para facilitar o cadastro de informações profissionais e a geração de currículos em PDF.

## Funcionalidades

* Cadastro de dados pessoais.
* Dois modelos de currículo:

  * **01 — Formação Acadêmica**
  * **02 — Formação Profissional**
* Cadastro de formação acadêmica.
* Adição de múltiplas formações.
* Objetivo profissional.
* Experiência profissional.
* Habilidades e cursos.
* Informações adicionais.
* Adição de foto pela galeria ou câmera.
* Geração automática do currículo em PDF.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* jsPDF

## Estrutura

```text
Protocolo-de-Curriculos/
├── index.html
├── style.css
└── script.js
```

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Escolha o modelo de currículo.
3. Preencha os dados solicitados.
4. Adicione uma foto, se desejar.
5. Clique em **Gerar PDF**.

Os dados são processados diretamente no navegador e não precisam de banco de dados.

## Objetivo

O projeto busca tornar o preenchimento e a criação de currículos mais simples, rápidos e organizados.
